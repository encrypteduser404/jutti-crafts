# Jutti Crafts Digital Archive

## Typography

Instrument Serif is used for display type and DM Sans for interface and body text. Both are loaded once from Google Fonts in `index.html`, with local system fallbacks defined in `src/styles/global.css`.

## Brand mark asset

The supplied `public/logo.jpg` is used in the centered header slot without cropping or stretching. Its light tinted square background remains visible against the ivory canvas; replace it with an approved transparent SVG or PNG when one is available rather than masking the JPG background in CSS.
